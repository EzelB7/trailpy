# Comandos linux

## Navegacion 

### 1. pwd
``` bash
pwd
```
muestra ubicacion actual / directorio actual 

### 2. ls 
``` bash
ls
```
Lista archivos 

### 3. cd 
```bash
cd  
```
Sirve para cambiar de carpeta o directorio

### 4. touch 
```bash 
touch 
```
Touch sirve para crear un tipo de archivo con una extension definida
por el programador


```bash
5- mkdir carpeta
```
Sirve para crear una carpeta/directorio

```bash 
6- rm archivo
```
Sirve para eliminar un archivo
